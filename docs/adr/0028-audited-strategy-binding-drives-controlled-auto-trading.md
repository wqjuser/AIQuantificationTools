# 已审计策略绑定驱动受控自动交易

策略工坊不再只保存用于纸面研究的策略版本，回测实验室也不再用前端研究闸门推断生产资格。操作者可以把服务端复核通过的已审计策略版本交接给现有自动交易评估链，但“运行回测、交接策略、授权实盘、启动监控、立即评估、提交订单”保持为不同操作。当前生产路由仍只支持 `crypto / BTC/USDT / 1m`，其它上下文明确阻断。

后端只接受策略修订、审计运行 ID、实名操作人和显式确认，不接受浏览器提供的策略正文。服务从既有策略库和研究运行库重新加载证据，复算规范策略修订、市场快照身份和完整审计内容哈希；先按原费用与滑点复现指标、成交和权益曲线，再按至少 `10 bps` 手续费与 `10 bps` 滑点做更保守重放。原审计结果或保守重放的最大回撤超过策略上限时不得绑定。

回测实验室通过只读预检读取同一套服务端校验结果，只显示“可交接、已交接、证据通过但暂不可切换、不可交接”之一。预检不写控制状态或审计事件；实际交接继续复用现有自动交易控制接口，并在写入前重新执行完整校验。运行回测只创建研究与回测证据并刷新预检，不会自动交接、授权、启动、评估或下单。

自动交易与回测共享同一组策略条件求值函数，均线、相对强弱指标和成交量条件不复制第二套算法。行情读取长度按已绑定策略的条件动态计算；统一决策契约、组合目标、风险调整目标、订单意图、交易所规范化、Stage 10 权限、急停、账户覆盖、单笔 `10 USDT` 上限、幂等提交和终态对账继续使用原链路。

用户已确认整个 Binance Spot 现货账户专用于本系统自动交易。测试网与生产模式以交易所只读账户快照作为实物资产数量、锁定数量和可用余额的权威来源，并把所有可通过直接现货交易对按 USDT 计价的非零资产纳入账户总净值。首次采用快照建立风险基线；此后无法由本系统已确认成交解释的充值、提现或账户内兑换作为外部资金流同步账户结构，并按净 USDT 资金流等额调整初始、日初和峰值风险基线，不计入策略盈亏，等值兑换的净资金流为零。全局运行要求账户估值完整、没有任何未决现货挂单且账户指纹与已绑定账户一致；无法估值、快照不一致、读取失败或账户指纹变化都失败关闭。账户持有其它币种不构成全局资金不足，但每笔 BTC/USDT 委托仍在提交前校验所需源币种的可用余额，买入只使用 USDT、卖出只使用 BTC，不自动兑换其它资产补足订单。

策略切换只允许在自动监控已暂停、权威账户快照中的当前策略基础币空仓且没有未决或待对账委托时完成。绑定时在既有自动交易状态中固定规范策略快照、快照全哈希、策略修订、审计运行 ID 和审计内容哈希，只清除上一策略的 K 线判断缓存；状态与策略绑定审计事件在同一事务中提交。资金、权益、已实现盈亏、尘埃、当日风险基线与停机原因、小时成交时间和历史订单证据全部保留。绑定完成后仍保持暂停。重复提交同一策略与同一审计运行只回读当前绑定，不续期生产授权。

每轮评估重新核验策略库与绑定时固定的审计证据。策略库可以把同一修订指向更新的回测运行，现有生产绑定仍按固定的审计运行 ID 与内容哈希工作；新运行只成为下一次显式交接候选。空仓时固定证据发生漂移会失败关闭并禁止开仓；已有持仓时使用绑定时固定且重新校验哈希的策略快照继续执行止损、止盈和退出条件，但禁止新增风险。固定快照本身缺失、被改写或上下文不一致时停止自动路由并要求人工处理，不允许持仓中换规则来绕过证据问题。

自动交易控制、策略绑定、委托意图、成交和尘埃处置属于本地运行域，不属于研究运行。它们在元数据中引用策略修订、审计运行 ID 和审计哈希，但 `runId` 保持为空；研究包导入明确拒绝所有自动交易运行域事件。重启恢复只读取同一 API 数据卷中 `runId` 为空、来源和阶段正确、结构完整的本地委托意图；稳定事件 ID 冲突时，运行模式、订单、订单意图和交易意图必须与本轮规范内容完全相同，否则在调用交易所前失败关闭。

AI 评审继续只形成研究证据和只追加的人工研究决策，不获得生产授权、启动、评估或委托能力。页面只在权威评审、本地确定性结论、外部补充结论、最新人工决策及其评审记录哈希和证据哈希全部匹配时展示后续生产路径；最新决策未接受时保持阻断。

评审选中的候选版本若不同于源研究运行的策略版本，必须先采用候选草稿、清除不再匹配的旧审计证据，并从策略工坊重新运行完整研究链。候选版本与源版本相同时，AI 评审页只读取既有服务端生产预检与当前生产绑定；预检运行、策略版本和快照身份必须与当前评审一致，失效或阻断的旧绑定不得显示为可用。实际交接仍在回测实验室实名确认。页面不能直接绑定生产策略、授权会话、启动监控、立即评估或提交订单。

组合风控继续保留阶段 4 / M5 的研究模拟链，同时只读投影既有自动交易状态中的当前策略绑定、运行健康、账户覆盖、双回撤、小时额度、风险调整目标和生产授权。生产健康必须同时满足后台心跳、风险停机、账户覆盖、绑定证据和现有生产门禁；最近一次决策不能冒充当前策略绑定。首版生产后端仍是单策略、单标的，只有当前研究组合恰好为一个组合腿且其审计运行与生产绑定完全匹配时才声明覆盖，其余情况明确显示为独立生产链，不把多标的研究组合解释为已接入实盘。页面只提供状态刷新和前往动态交易复核，不绑定策略、不授权、不启停、不评估也不提交订单。

执行中心复用同一个自动交易快照展示已持久化的运行模式、生产策略绑定、标的周期、运行器、策略账本、风险边界、委托台账和生产会话，不新增轮询、Store 或执行状态机。已审计策略的信号与触发条件由绑定版本固定，页面不再展示只适用于内置策略的智能决策服务和涨跌幅阈值；本页继续只调整执行模式、委托额度与账户级风控。表单中尚未保存的模式不能冒充当前运行状态，绑定证据阻断时不能开启监控或人工触发新评估，但既有未决委托仍可沿用原路径只读对账。

生产会话状态以自动交易快照顶层门禁为权威。快照读取失败时立即撤销前端快照可信性，页头、执行中心和全局底栏均不得回退到设置缓存宣称生产路由可用；实名授权或续期成功后立即回读同一快照。已经有效的会话不会因为 Stage 10 启动核验证据过期而误显示为已撤销；页面明确提示续期或重新授权前仍需更新凭据、权限与急停证据，并且每笔新委托仍会实时复核权限、急停、账户覆盖和风险边界。Stage 10 保留原有显式动作，不会因页面加载、轮询或状态投影自动核验、恢复、续期、评估或提交委托。

运行管理复用同一自动交易快照与服务端监控状态，只读汇总当前执行模式、活动策略、后台心跳、最近判断、委托结果、策略账本风险、账户覆盖、生产授权和服务端事件。生产状态读取失败时保持不可用，不回退为纸面模拟；策略绑定证据缺失时明确待确认，不用最近判断冒充活动策略。原研究队列、扫描器、研究验证节点、数据源健康和市场日历继续作为次级研究维护工具，并明确其模拟证据不代表生产运行状态；AI 已评审候选只导航到既有执行中心复核生产交接，不再从运行管理自动提交模拟委托。页面只允许导航到动态交易、执行授权和审计回放，不自动评估、对账、授权、急停、切换模式或提交委托。

动态交易借鉴“任务经济账本”的可解释性，但只接受本系统已有的真实证据。自动交易快照在现有策略账本上汇总已实现与未实现盈亏、成交手续费和外部模型调用遥测，并另行展示专用 Binance Spot 账户权威总净值；账户净值用于账户级风险，策略盈亏只按本系统成交归因，充值、提现、账户内兑换和其它资产重估不能伪造成策略收益。成交手续费已经进入平均成本与已实现盈亏，只单列归因而不重复扣减，卖出以基础币扣费时按实际减少的持仓成本结算。旧成交费用从同模式、同标的审计事件恢复；模型调用异常、用量字段缺失或旧模型用量无法完整恢复时明确标记不完整。调用遥测只表示未发现的已知缺口，不是服务商账单级完整性。没有服务商账单或显式历史计价时，模型金额成本与扣除模型成本后的净盈亏保持不可得，不用令牌数量、虚拟任务金额、排行榜或硬编码价格制造“营收”。纸面与测试网继续标为模拟金额。
