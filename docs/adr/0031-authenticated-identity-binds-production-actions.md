# 认证身份替代浏览器实名字段并约束生产授权

## 状态

Accepted

## 背景

local 页面允许用户填写 operator/reviewer 等审计文字。公网中若继续信任浏览器字段，用户可以伪造其他操作者，并绕过生产授权责任边界。

## 决策

public 模式的当前操作者只来自有效 OIDC 会话中的已验证邮箱。浏览器顶层 `operator`、`reviewer`、`author`、`approvedBy` 和 `liveOperator` 必须与当前身份一致；`owner_id` 永远由服务端注入。导入制品内部的历史作者属于规范内容，不能被当前会话改写。

修改生产密钥、开启或续期生产会话、恢复 Stage 10 控制要求最近 5 分钟 OIDC 重新认证。重新认证只恢复身份新鲜度，不能替代既有风险确认、权限核验、急停、账户覆盖、策略证据和 Stage 10 授权。

退出或会话过期阻断新的人工授权，但不停止已有未决订单的只读对账。活动生产凭据指纹跨租户唯一，生产控制和后台执行使用 PostgreSQL lease。

## 结果

- public 审计操作者不可由浏览器任意伪造。
- OIDC 身份不宣称法律实名、KYC 或金融合规身份。
- local 模式继续保留现有人工字段兼容。
- 本 ADR 取代早期 ADR 中“浏览器具名字段等同可信单操作者”的假设；研究/交易分离和风险门禁保持不变。
